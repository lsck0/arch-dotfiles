# ff14 dalamud theme

Styles Dalamud and plugin windows; the game HUD is arranged in-game with
`/hudlayout`.

## Apply

`/xlsettings` > Look & Feel > Style Editor:
1. Add a style named `cyberpunk`.
2. Enter the colors from `palette.md` (Colors tab) and the sizing below
   (Variables tab).
3. Set it as the active style.

Sizing:
- WindowRounding 2, ChildRounding 2, FrameRounding 2, PopupRounding 2
- GrabRounding 2, TabRounding 2, ScrollbarRounding 2
- WindowBorderSize 1, FrameBorderSize 1
- WindowPadding 8,8  FramePadding 6,3  ItemSpacing 6,4

`cyberpunk-dalamud.json` holds the same values.
