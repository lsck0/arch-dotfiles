# socials

- `desktop` is a tms/herdr project bookmark (`.tms-create`, `.herdr-create`), not an app.
- `discord`: the first apply downloads the client; BetterDiscord plugins are content-pinned.
- CEF/Chromium clients run native Wayland, not scaled XWayland.
- Clients with an AppArmor profile run enforce; teamspeak6-client, proton-meet-bin, chatuino-bin and discordo-git have
  none yet.
